# 집/회사 모드 전환 기능 구현 완료 (2026-02-15)

## 1. 개요

사용자가 식사 장소를 **집** 또는 **회사** 중 선택하면, 해당 위치 주변의 추천 메뉴와 식당 정보를 즉시 갱신하여 보여주는 기능입니다.

## 2. 변경된 파일

- `src/app/agent/page.tsx`

## 3. 주요 구현 내용

### ① 선택 상태 관리 (State)

- 현재 선택된 모드(`"home"` 또는 `"company"`)를 저장하는 `locationMode` 상태를 추가했습니다.
- 기본값은 **집(home)** 입니다.

```tsx
const [locationMode, setLocationMode] = useState<"home" | "company">("home");
```

### ② 화면 UI (Button)

- **식단 계획 제공** 섹션 제목 옆에 **[집 | 회사]** 토글 버튼을 배치했습니다.
- **shadcn/ui**의 `Button` 컴포넌트를 사용해 깔끔한 디자인을 적용했습니다.
- 선택된 버튼은 색상(indigo/purple)으로 강조되고, 선택되지 않은 버튼은 회색(ghost) 처리됩니다.

### ③ 데이터 연동 (Logic)

- 버튼을 클릭하면 `locationMode`가 변경됩니다.
- `useEffect`가 이를 감지하여, `localStorage`에 저장된 주소 중 **선택된 모드에 맞는 주소**를 찾습니다.
- 해당 주소 기반으로 `fetchMenuSave` API를 재호출하여 식당/메뉴 데이터를 새로 받아옵니다.

## 4. 기대 효과

- 사용자가 상황에 맞춰 **클릭 한 번으로** 집 근처 식단과 회사 근처 식단을 손쉽게 전환하며 볼 수 있습니다.
- 불필요한 페이지 이동 없이, 한 화면에서 두 가지 컨텍스트의 정보를 모두 제공합니다.
